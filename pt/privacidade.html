Política de Privacidade

Atualizado em: 30 de outubro de 2026

Quem mantém o DarknessBot

O DarknessBot é um bot de Discord gratuito, feito e mantido por Adriano Junior (Discord: juniorstofel), desenvolvedor independente no Brasil. O jeito mais rápido de falar comigo é o servidor Darkness, no link no fim desta página.

O que o bot guarda

  • Vínculo com a conta Riot. Quando você usa /lol vincular, o bot guarda o seu ID de usuário do Discord, o seu PUUID da Riot, o seu Riot ID (nome e tag) e a data do vínculo. Nada é guardado antes de você usar esse comando.
  • Mensagem do player de música. Para cada servidor, o ID do canal e da última mensagem do player, para a sessão seguinte apagar a antiga.
  • Registros do servidor. O bot escreve registros técnicos (erros e linhas como um ID do Discord vinculando um Riot ID). Eles ficam no servidor onde o bot roda e não são repassados a ninguém.

O que o bot lê, mas não guarda

  • Dados do League of Legends pela API da Riot Games (elo, maestria, partida ao vivo, desafios), buscados quando alguém usa um comando. Os dados da partida ao vivo são reaproveitados por 60 segundos, depois descartados, e nunca são gravados em disco.
  • Buscas de música, enviadas ao YouTube pelo servidor de áudio do bot para achar a música. Não são guardadas.
  • Comandos e as opções deles, para responder. O conteúdo das mensagens do seu servidor não é lido, exceto as mensagens que o /clear apaga quando um moderador pede.

O que nunca fazemos

Não vendemos, alugamos nem repassamos dados. Sem anúncios, rastreadores ou análise de uso, no bot ou neste site. Este site não usa cookies e não carrega nada de outros sites.

Apagar os seus dados

Use /lol desvincular e o seu vínculo com a Riot é apagado na hora. Para pedir que qualquer outra coisa seja apagada, ou uma cópia do que está guardado sobre você, fale comigo no servidor Darkness. O registro do player de um servidor é uma linha só (ID do canal e da mensagem); é só pedir que eu apago.

Serviços que o bot usa

Discord (onde o bot roda), a API da Riot Games (dados do League of Legends) e o YouTube (música). Cada um tem a sua própria política de privacidade. O bot roda num servidor privado (VPS) alugado pelo desenvolvedor. Este site é hospedado pelo GitHub Pages, que mantém registros de acesso comuns (como o endereço IP) conforme a declaração de privacidade do próprio GitHub.

Crianças

O DarknessBot é para pessoas com idade para usar o Discord, pelas regras do próprio Discord.

Mudanças

Se esta política mudar, a data no topo muda junto, e mudanças grandes são avisadas no servidor Darkness.
